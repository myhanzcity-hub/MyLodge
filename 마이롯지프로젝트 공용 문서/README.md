# 마이롯지프로젝트 공용 문서

기존 PC의 프로젝트 원본 자료를 노트북과 공동 작업 환경에서 참고하기 위해 보관한다. 2026-09-28 복사했으며 원본 내용은 수정하지 않았다.

## 자료 목록

- `마이롯지 (공유별장) 사업 계획서 배포.pdf`: 사업 계획 자료. 파일명에 배포가 포함되어 있어도 웹사이트 공개 다운로드 승인을 의미하지 않는다.
- `마이롯지_플랫폼_기획서_20260924_v0.1.docx`: 플랫폼 기획서.
- `마이롯지_홍보페이지_개발순서_보고서_20260924_v0.1.docx`: 개발 순서 보고서.
- `통화 IMT 대표_260924_102948_전사.json`
- `통화 IMT 대표_260924_102948_전사_medium.json`: 같은 통화의 전사본 두 종류. 자동 전사 오류 가능성이 있으므로 중요한 조건은 PM 확인이 필요하다.

최신 사용자 결정과 미완료 사항은 `../docs/CODEX-HANDOFF.md`를 먼저 확인한다. 원본 기획 자료와 이후 사용자 결정이 다르면 최신 합의 사항을 확인한다.

## 배포 시 반드시 제외

이 폴더는 저장소에서 공유하는 내부 참고 자료이며 공개 사이트용 파일이 아니다. 통화 전사, 원본 기획서, 개발 보고서, 작업 인수인계 문서는 사이트에 공개하지 않는다. 소개서 다운로드는 사용자가 제외 요청한 상태다.

현재 `scripts/build.mjs`는 index.html, styles.css, app.js 세 파일만 dist로 복사하고, Vercel은 dist만 배포하므로 이 폴더는 공개 산출물에 포함되지 않는다. .gitignore에 넣으면 노트북에서 받을 수 없으므로 Git 추적은 유지한다.

향후 배포 점검 또는 공개 범위를 질문받으면 이 제외 사항을 다시 안내한다. 빌드 방식·출력 폴더·호스팅 서비스를 변경할 때 저장소 전체 또는 이 폴더를 공개하지 않는지 반드시 확인한다. 원본 자료를 public/static/dist 폴더로 복사하지 않는다.
