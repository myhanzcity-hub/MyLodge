## 근거 사용에서 제외한 관찰

- 최초 `.press('Tab')` 방식은 정지 버튼을 거쳐 외부 링크로 초점이 넘어갔다. `390-ko-gallery-focus-observation-*` 표본은 초점 중 재생 증명에서 제외하며 `validForFocusClaim=false`로 표시했다.
- 18초 간격 표본은 장면을 건너뛸 수 있다. 표본의 숫자 차이만으로 실제 자동 전환 간격을 계산하지 않는다. 시간 설계값은 코드의 계산식을 근거로 기록한다.
- O22–O23은1초 간격으로 장면 변경을 기록했지만, 감지 시각에는 표본 간격·도구 지연이 포함된다. 정확한 타이머 성능 측정으로 표현하지 않는다.
- PC의 마우스 드래그는 `pointerType==='touch'` 코드 경로를 검증하지 않는다. 실제 스와이프를 성공했다고 주장하지 않는다.
- 로컬 이미지는 관찰한 시점에 로드돼 있었다. 통신 장애나 느린 연결에서의 빈 이미지 현상은 아직 발생시켜 확인하지 않았다.

## 관련 파일

- `mobile-layout.js`: 터치 판별·세로 이동·취소·앵커 이동·popstate.
- `app.js`: 사진 갤러리 상태와 타이머, 메뉴, 현재 카테고리 표시.
- `editorial.js`: 생활 슬라이드, 장면 카피와 사진 교체, 시간 계산.
- `intro.js`: 영상의 메뉴·화면 밖 중단과 실패 처리.
- `styles.css`, `mobile-layout.css`: touch-action 및 조작 배치.
- `localization.js`, `branding.js`: 언어 링크와 패널.
- `chairman.js`: 시설 탭의 선택·키보드 이동.

실제 개발 페이지 관찰은 `direct-page-observations.json`에 별도 저장한다. 브라우저 viewport 변경도 실제 기기 입력·OS 회전과 동일하지 않다.
