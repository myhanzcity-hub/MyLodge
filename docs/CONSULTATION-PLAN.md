# 실제 상담 접수 방식 제안

상태: 2026-09-25 사이트에 접수 예정 흐름 안내 반영. 실제 저장·전송 구현은 후속 파트입니다.

## 권장 방식

사이트 상담 양식 → 서버 검증·저장 → 접수번호 표시 → 로그인한 직원의 접수 목록 → 처리 상태 관리.

회원 가입 기능과 분리하여 상담 접수 파트를 먼저 구현합니다. 방문자는 가입 없이 문의하고 직원만 로그인합니다.

## 접수 파트에서 구현할 내용

- 필수: 이름, 연락처, 개인정보 수집 안내와 동의.
- 선택: 관심 지역, 연락 가능 날짜·시간, 문의 내용. 2026-09-27 사용자 요청으로 주문진·양양 소개와 관심 지역 항목을 복원했습니다.
- 서버 저장 성공 시에만 접수 완료와 접수번호 표시.
- 중복 제출 방지, 입력 검증, 오류 시 재시도, 기본 스팸 방지.
- 직원 목록: 신규 / 연락 중 / 상담 완료 상태와 담당자.
- 고객 문의 내용과 연락처는 공개 목록에 표시하지 않음.
- 운영 승인 후 보관기간·삭제 방식·문의처와 실제 담당자 확정.

## 완료 기준

시험 접수 한 건이 고객 접수번호와 직원 목록에 동일하게 나타나고, 권한 없는 사용자는 조회할 수 없어야 합니다. 저장 실패 시 완료 안내를 표시하지 않는 것도 확인합니다.

외부 상담 폼이나 회사 채널을 사용하려면 실제 운영 링크와 담당자가 먼저 필요합니다. 현재는 링크가 제공되지 않았습니다.
