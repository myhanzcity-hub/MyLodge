# 전체 화면·모션 중간 점검 — 2026-09-29

## 요청과 범위

전체 사이트를 살펴보고 단조로운 효과를 보완해 달라는 요청과, 참여 절차 4번째 항목이 혼자 다음 줄로 떨어지는 화면을 고쳐 달라는 추가 요청을 반영했다. 기존 서버 기능 보류 결정은 유지한다.

## 확인한 문제와 수정

1. **참여 절차의 3+1 배치 / 숫자 정렬**: 기존 auto-fit 그리드가 중간 화면에서 3열이 되어 마지막 단계가 외롭게 떨어졌다. 뒤쪽 CSS의 `display:block`이 숫자 중앙 정렬도 덮었다. 1180px 이상은 4열, 600–1179px은 2×2, 599px 이하는 번호·연결선이 있는 세로 타임라인으로 변경했다. 숫자는 44px 원 중앙에 배치한다. 호버 글자색과 배경색의 우선순위 충돌도 수정했다.
2. **중간 화면의 긴 프로젝트 구간**: 760px 이상에서 두 프로젝트를 나란히 배치한다. 900px 화면에서 수정 후 섹션 높이는 약 1059px이다. 이전 923px 화면에서는 약 2231px로 확인됐다. 작은 모바일은 한 열을 유지한다.
3. **후반 구간의 끊기는 움직임**: 진행 안내 제목과 공개 항목, FAQ 제목까지 기존 1회 등장 효과를 연결했다. 공개 항목의 이동은 18px, 지연은 80ms 간격이다. 실제 사업 진행률을 뜻하는 애니메이션은 추가하지 않았다.
4. **FAQ의 갑작스러운 펼침**: 280ms 높이·투명도 전환과 열린 질문의 배경 강조를 적용했다. 빠른 재클릭은 이전 애니메이션을 취소하고 현재 높이에서 이어간다. 검색·분류 변경은 즉시 상태를 확정한다. 닫히는 답변은 즉시 inert 처리하며 종료 후 hidden 처리한다.
5. **서비스 덱 높이 변화**: 상세 펼침과 카드 교체 시 덱 높이가 350ms에 걸쳐 바뀐다. 기존 비활성 카드의 높이 제한과 inert 처리를 유지한다.
6. **사진 패럴랙스 스타일 충돌**: 사진 덱 이미지의 기존 inset·음수 margin 조합을 단일 규칙으로 정리했다. 위아래 48px 여유를 확보해 ±24px 패럴랙스 중 사진이 마스크를 채우도록 했다.
7. **안내문과 다음 메뉴의 겹침**: 새로고침 후 참여 절차 안내문이 기존 scroll-pull 이동 때문에 아래 접기 메뉴와 겹치는 것을 확인했다. 절차·이미지 안내문과 서비스 카테고리 메뉴를 해당 이동 대상에서 제외해 읽기와 선택 위치를 안정시켰다.

- PC 첫 화면, 프로젝트, 사진 덱, 참여 절차, 준비 중 서비스, 진행 안내, FAQ 화면 확인. 모바일 공유 구조·비용·프로젝트·참여 절차·상담 확인.

- 모바일 예시 이름·번호 → 동의 화면 확인 → 내용 확인 → 체험 완료까지 진행. 실제 전송·저장 없는 화면 체험임을 완료 화면에서 확인.
- app.js 및 consultation.js 문법 검사 통과. 점검 중 수집된 브라우저 오류 로그 없음.

- 중간 화면 메뉴 열기·Escape 닫기, 양양 선택 후 상담의 지역 선택·요약 연동 확인.
