# 모바일 환경 재구축 — 2026년 10월 9일

## 적용 범위

홈페이지와 치앙마이 페이지, 별도 모바일 검토실 작업본에 동일한 모바일 레이아웃을 연결했다. 기존 점검 문서의 M01–M06, L01–L04, U01–U04를 기준으로 구조를 보완했다. GitHub/Vercel 배포는 보류한다.

## 구성

- 기기 폭 viewport 사용. 700px 이하를 1280px로 바꾸던 임시 스크립트를 두 페이지에서 제거했다. 확대 기능은 유지한다.
- 1023px 이하: 모바일 메뉴, 시설 탭 2열, 시설 이미지와 설명 세로 배치, 시설 특징 목록 표시.
- 800px 이하: 지역·오너·미래 비전·컨시어지 카드 1열. 사진 덱은 활성 사진 한 장을 표시하며 자동 재생 및 일시정지는 기존 제어기를 사용한다.
- 첫 영상은 전체 프레임을 보존하는 contain 방식과 내용 흐름의 조작부를 사용한다. 짧은 가로 화면에서도 버튼을 고정 영상 캔버스 밖으로 잘라내지 않는다.
- 생활 슬라이드는 이미지, 제목·본문, 캡션, 조작부를 순서대로 표시한다. 가로 회전 때 비활성 장면의 aria-hidden을 지우던 mobile.js 처리를 제거했다.
- 헤더 실제 하단 좌표 + 14px를 공통 이동 기준으로 측정한다. 내부 이동 시 메뉴와 언어 패널을 닫고 제목에 포커스를 옮긴다. 직접 해시 진입과 뒤로 가기도 처리한다.
- 긴 영문 강조 단어는 필요할 때 줄바꿈하도록 했다. 본문을 고정 높이 안에 숨기지 않는다.
- 헤더·푸터 로고의 투명 에셋과 밝은 보호 배경을 유지한다. filter와 mix-blend-mode에 의한 색 변형을 억제하고 푸터 로고 폭·패딩을 border-box로 정리했다.
- 모바일에서는 장면 진입 변형과 사진 패럴랙스를 줄인다. 콘텐츠 카드 이미지 sizes를 실제 카드 폭에 맞게 조정했다.

## 파일과 책임

- mobile-layout.css: 마지막에 연결하는 공통 반응형 레이아웃.
- mobile-layout.js: 헤더 측정, 모바일 내부 링크 이동, 카드 이미지 sizes.
- mobile.js: 기존 모바일 메뉴 보조 처리. 생활 슬라이드 접근성 상태는 수정하지 않는다.
- docs/mobile-preview-20261008/site/mobile-improvements.js: 검토실의 테마·글자 배율 설정만 담당. 이동 제어 중복 제거.
- 검토실과 실제 홈페이지가 같은 mobile-layout 파일을 사용한다. baseline은 변경하지 않았다.

## 확인 상태와 남은 검증

이번 개발 요청에서 테스트 명령이나 브라우저 검수는 별도로 실행하지 않았다. 아래는 검증 대기 항목이며 통과 결과가 아니다.

- 320/360/390/414/768/800/801/1023/1024px 첫 접속 및 PC에서 축소·확대 비교.
- 667×375, 844×390 가로 회전, 영상 버튼과 메뉴 전체 가시성.
- 한국어·영어, 검토실 글자 1배/1.5배/2배, iOS/Android 글자 확대.
- 메뉴 이동 후 제목 가림, 직접 해시 진입, 뒤로 가기, 이미지 로딩 이후 위치.
- 자동 슬라이드 일시정지 유지, 회전 전후 단일 활성 장면, 모션 줄이기.
- 실제 Android/iOS의 OS 테마 및 브라우저 강제 다크모드 로고 색상. CSS 보호 규칙만으로 제조사별 강제 변환 해결을 확정하지 않는다.
