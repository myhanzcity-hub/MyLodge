## 후속 파트

각 파트는 구현 → 확인 → 수정 → 완료 확인 후 다음 단계로 진행한다.
기간은 자료·운영 담당·사용 도구 확정 후 조정한다.

1. 범위와 자료 확정 (보고서 T0~T2)
   - 상담형 공개 범위, 상품·가격 기준, 상담 담당, 승인 자료 정리
   - 완료 기준: 공개할 것·보류할 것·담당자가 정해짐
2. 화면 완성 (T3 화면 부분)
   - Figma 대조, 모바일, 메뉴·입력란·상태 화면 점검
   - 완료 기준: PC와 모바일에서 안내 확인과 상담 입력이 가능
3. 실제 상담 접수와 직원 확인 (T3 운영 부분, T4)
   - 저장, 접수번호, 직원 접근, 처리 목록, 오류·중복 대응
   - 완료 기준: 시험 신청 한 건을 담당자가 확인하고 처리 상태 변경 가능
4. 공개 내용과 운영 정리 (T5)
   - 회사·가격·FAQ·개인정보 안내 승인본과 갱신 방식
   - 완료 기준: 운영자가 승인된 자료를 관리 가능
5. 통합 점검과 공개 (T10~T11)
   - 권한·접수·실패 처리·화면·복원 시험 및 운영 인수인계
   - 완료 기준: 승인 후 실제 공개 주소에서도 정상 처리 확인

사진·영상·모집 현황·방문 신청·맞춤형 소개(T6~T9)는 자료와 운영이 준비된 순서로 확장한다.
실제 계약·결제·회원 예약·교환·렌트는 별도 개발 범위다.
