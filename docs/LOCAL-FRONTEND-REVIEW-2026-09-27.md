# 로컬 기능 추가 및 디자인 점검 — 2026-09-27

## 작업 범위와 배포 상태

- 상담 주제 선택과 FAQ 분류를 로컬에 반영했다.
- Git 커밋·푸시 및 Vercel 배포는 하지 않았다. 공개 사이트에는 반영되지 않았다.
- 실제 접수·DB·관리자·알림·회원 서비스는 PM 협의 후 진행한다.

## 추가한 기능

1. 상담 주제: 비용·분납, 공동소유, 이용 방법, 기타 중 하나를 선택하는 선택 항목. 선택 해제 및 체험 완료 후 초기화.
2. FAQ: 전체, 소유·참여, 비용·납입, 이용·서비스, 취소·환불로 기존 8개 질문 분류. 결과 수 표시 및 분류의 첫 답변 펼침.

## 이번 점검 결과

- JavaScript 문법 검사와 정적 빌드 통과.
- 로컬 브라우저에서 비용·납입 선택 시 3개 질문, 전체 복귀 시 8개 질문 표시 확인.
- 상담 주제 한 개 선택 및 선택 해제 동작 확인.
- 좁은 화면(390px)에서 추가한 상담 주제 2열 배치 확인.
- 기존 초록색 계열과 둥근 테두리 적용. 선택 항목은 색상 외에 라디오 표시로 구분.
- 최소 44px 조작 높이 및 키보드 포커스 표시 적용.

## 개선 제안 (아직 적용하지 않음)

- 상담 질문이 여러 분야에 걸친다면 주제를 복수 선택으로 바꾸는 방안을 검토. 현재는 가장 궁금한 한 가지 기준.
- 기타 선택 시 문의 입력란에 예시를 안내하면 작성이 쉬워질 수 있다.
- FAQ에 확정된 답변이 늘어나면 검색 추가를 검토. 현재 8개 질문에는 분류만 적용.
- 긴 상담 폼의 단계 구분 및 고정 하단 버튼과의 관계는 전체 화면 점검 때 확인.

## 추후 점검 예정 — 다음에 미완료 항목을 물으면 안내

- 사용자 요청 2번: 모바일·PC 전체 레이아웃과 메뉴·입력·날짜·시간·상태 화면 종합 점검은 보류.
- Figma 원본과의 세부 대조는 미완료. 이번 점검은 추가된 기능과 디자인에 한정.
- 상담 운영 종료 시각 및 당일 이미 지난 시간 허용 여부는 PM 확인 필요.
- PM 자료 수령 후 공식 소개서, 회사 정보, 개인정보 처리방침·이용약관, 실제 문의처 반영.

## 5번 항목 설명

### 후속 반영 완료

- 사용자가 소개서를 제외한 항목의 추가를 요청하고, 실제 자료는 '준비 중'으로 표시하도록 답변했다.
- 하단에 회사명·대표자·사업자등록번호·주소 및 전화·이메일·상담 채널·운영시간을 준비 중 상태로 추가했다.
- 개인정보 처리방침·이용약관·문의 안내 버튼은 개별 안내 팝업을 연다. 승인 문서나 연락처를 임의로 작성하지 않았다.
- 로컬에서 세 팝업의 내용, 닫기 버튼 및 Escape 닫기와 빌드를 확인했다.
- 소개서는 추가하지 않았다. GitHub·Vercel 반영은 하지 않았다.
- PM 자료 수령 시 실제 내용으로 교체하는 작업은 계속 미완료 항목이다.

공식 소개서는 PM 승인 PDF를 방문자가 내려받는 기능이다. 회사 정보는 운영 회사명·사업자 정보 등 공개 승인된 정보를 하단에 표시하는 것이다. 정책은 승인된 개인정보 처리방침과 이용약관을 읽을 수 있게 하는 것이다. 문의처는 승인된 전화·이메일·상담 채널과 운영시간을 안내하는 것이다. 정적 파일 및 링크로 구현 가능하며 DB가 필요하지 않다. 현재 임시 안내를 실제 자료로 교체하는 작업이며 자료 수령 전 임의로 확정하지 않는다.
