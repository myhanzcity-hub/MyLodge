# 모바일 재검수 및 수정 — 2026년 10월 9일

## 발견하고 수정한 문제

1. **전체 단지 전경의 과도한 잘림:** 모바일 figure가 1.1:1 비율을 상속해 가로 사진의 좌우가 사라졌다. 16:9 프레임과 contain, 변형 없는 이미지로 수정했다.
2. **사진 갤러리의 PC 오프셋 잔존:** 이미지 top -32px, 높이 +64px로 상하가 확대됐다. 모바일 이미지를 inset 0, 높이 100%, contain으로 정리했다.
3. **갤러리 폭이 좁아짐:** display:grid 변경 후에도 PC의 2열 grid-template-columns가 남았다. 단일 열을 명시하고 화면 전환 중 변형 transition을 제거했다. 390px 설정에서 이미지 실측 338×189px, transform none.
4. **200% 확대 시 긴 영문 강조 넘침:** tech community의 nowrap이 다른 모바일 규칙보다 우선했다. 정확한 선택자로 줄바꿈과 최대 폭을 적용하고 제목 그리드의 최소 폭을 0으로 지정했다.
5. **확대 배율 일부 누락:** 작은 화면의 시설·미래 비전·길잡이·마지막 제목 크기가 고정 px 규칙에 덮였다. 공통 배율을 사용하는 rem 계산으로 통일했다.
6. **가로 모바일의 이미지 규칙 누락:** 844px 가로 휴대폰에 800px 전용 보완이 적용되지 않았다. 1023px 이하이면서 높이 500px 이하인 조건에도 같은 이미지·카드 구성을 적용했다.

문구와 이미지 원본은 유지했다. 공통 mobile-layout.css와 별도 모바일 작업본에 동일하게 반영했다.
