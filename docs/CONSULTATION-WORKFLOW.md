# 상담 화면과 운영 시연 구현

작성: 2026-09-28. 오후 중간 저장 이후 재개한 로컬 프런트엔드 작업 기록.

## 적용 범위

PM-REVIEW-20260928.md의 ‘지금: 서버 없이 보완’ 범위를 구현했다. 실제 상담 공개 준비 완료나 서버 시스템 구현을 뜻하지 않는다.

### 고객 상담 화면

- 기본 입력: 이름, 휴대전화, 선택 프로젝트, 체험 안내 확인.
- 추가 정보: 주제·서비스·희망 시간·질문은 접힌 선택 영역에 배치.
- 시간: 미지정과 시간 무관을 구분. 가까운 7일 또는 달력 → 오전/오후/저녁 → 원하는 경우 정확한 시각.
- 날짜 변경은 시간대·시각을 초기화하고, 시간대 변경은 이전 시각을 해제.
- 한국 시간 기준으로 지난 시각을 비활성화하며 확인창의 완료 동작에서도 다시 계산.
- 연락처와 희망 시간을 강조한 확인창, 항목별 수정 이동, 입력 보존.
- 공개 폼은 실제 접수·전송·저장 없이 체험 완료만 표시.

### 운영 시안

- 업무 묶음: 전체, 미배정, 오늘 연락, 기한 경과, 재연락 필요. 묶음은 중복될 수 있다.
- 문의 번호·고객·프로젝트·주제로 검색. 상태와 담당자 필터를 함께 사용.
- 최초 고객 입력과 운영자의 담당자·상태·연락 결과·다음 일정·행동·메모 분리.
- 연락 예정은 담당자/일정/행동을 요구. 상담 중과 재연락은 담당자/행동 및 일정 또는 미정 사유를 요구.
- 종료에는 담당자와 종료 결과를 요구. 부재 상태에서 안내 완료·참여 검토로 바로 종료하지 않는다.
- 저장 시 실제 변경 항목의 이전/이후 값만 이력에 추가. 변경이 없으면 이력도 추가하지 않음.
- 이미 기한이 지난 문의의 단순 메모 수정은 허용. 상태·연락 결과·일정을 바꾸면서 과거 일정을 유지하면 재설정을 요구.
- 다른 문의·필터·탭으로 이동할 때 미저장 변경에 대해 계속 작성/버리기/저장 후 이동 제공.
- 새로고침·페이지 이탈 시 작성 중 내용이 있으면 브라우저 경고. 브라우저의 경고 표시 정책은 환경에 따라 달라질 수 있다.
- 날짜가 바뀌어 현재 업무 묶음에서 벗어나면 상세에 안내하고 편집은 유지.
- 모바일에서는 문의 카드를 가로 목록으로 배치하고 선택한 문의 상세로 이동. 동작 줄이기 설정 반영.

## 가상 문의를 이어서 보는 방법

1. `npm start` 후 http://127.0.0.1:4173/workflow.html 열기.
2. ‘가상 상담 만들기’를 선택. 가상 고객 D의 이름/연락처는 고정됨.
3. 관심 프로젝트와 필요한 선택 정보를 작성하고 체험 확인란을 선택.
4. 입력 확인 → 가상 문의 생성 → 운영자 화면에서 이어보기.
5. 같은 DEMO 번호의 문의에 담당자를 지정하고 연락 일정과 다음 행동을 저장.
6. 고객 부재 상황에서는 재연락 필요로 변경하고 다음 일정 또는 미정 사유를 기록.
7. 상담 종료 시 종료 결과를 기록. 계약·모집 구좌 수는 바뀌지 않음.

접수 상황은 정상 / 첫 저장 실패 / 응답 지연 / 알림 실패 중 선택한다. 응답 지연에서는 기존 접수 결과 확인을 먼저 진행하고 같은 토큰으로 새 문의를 만들지 않는다. 알림 실패는 문의 저장 상태와 분리하며 운영 화면의 알림 재처리 시연으로 변경할 수 있다. 실제 메시지 발송은 없다.

## 파일 구조와 실행

- index.html / app.js: 공개 사이트와 공통 폼 마운트.
- consultation.js / consultation.css: 고객용·가상 고객용 공통 폼.
- workflow.html / workflow.js / workflow-model.js: 운영 시연 페이지·화면·메모리 상태 모델.
- workflow.css / workflow-layout.css: 운영 화면 스타일과 공개 사이트 전역 스타일의 영향 제한.
- /admin-demo.html URL도 새 운영 시안으로 연결. 디스크의 admin-demo.html은 과거 시안으로 보존.
- server.mjs는 localhost 정적 미리보기 서버이며 실제 접수 API가 아니다.
- `npm run build`는 index.html, styles.css, app.js, consultation.css, consultation.js와 AI 콘셉트 이미지 5개를 dist에 복사한다. 운영 페이지와 내부 문서는 제외한다.
- 실행 환경 Node.js 20 이상. 패키지 추가 설치 없음.

## 작업 기록과 한계

- 로컬 공개 파일 빌드 완료. 고객 상담 화면과 운영 시안을 브라우저에 표시했다.
- 자동 테스트·폼 제출 시나리오 실행 검증은 진행하지 않았다. 실서비스 공개 전 종합 검증은 별도 작업이다.
- 모든 가상 문의/메모/이력은 메모리에서만 유지되며 새로고침하면 초기화된다. localStorage/sessionStorage나 외부 저장소를 사용하지 않는다.
- 인증·권한·동시 편집·서버 중복 방지·실제 발송 재시도는 구현하지 않았다. 화면의 시연 로직을 운영용 보장으로 해석하지 않는다.
- 09–23시는 선택 UI의 예시다. 운영시간·휴일·마감 버퍼·응답 목표는 승인되지 않았다.
- 서버, 사업 조건, 개인정보 처리 정책, 공식 문의처, 계약·예약·교환·결제는 PM 협의 전 보류.
- GitHub 반영과 운영 배포 없음.
