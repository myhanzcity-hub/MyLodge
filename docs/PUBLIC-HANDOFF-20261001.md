## 반영 내용

- 가족의 아침 식사 전체 화면, 아침→오후→저녁 스크롤 생활 장면.
- 큰 제목, 움직이는 문구 띠, 사진 확대/패럴랙스 및 프로젝트 좌우 등장.
- 참여 안내의 빛 궤도, 입체 카드·조명·광택, 문서/안내 카드 연출.

- 사진은 AI 또는 사업계획서 콘셉트로 표기. 실제 고객·현장·제공 서비스로 표현하지 않음.
- 검토 중 가격과 미정 조건 유지. 서버·DB·회원 인증·실제 접수/발송/예약/결제는 PM 협의 전 보류.

## 시작

Node.js 20 이상. 추가 패키지 설치 없이 npm start로 로컬 실행, npm run build로 공개 dist 42파일 생성. 사이트 화면은 app.js/styles.css 및 cinematic.js/cinematic.css가 담당한다. 모바일 및 모션 감소에 대한 정적 대체를 제공한다.

이 브랜치의 Vercel Git 자동 배포는 비활성화되어 있다. main 병합 없이 업로드한다. 내부 상담 운영 소스의 후속 수정·연구 문서·원본 PNG·백업·검토 자료는 이번 업로드에 포함하지 않고 로컬에 보존했다.
