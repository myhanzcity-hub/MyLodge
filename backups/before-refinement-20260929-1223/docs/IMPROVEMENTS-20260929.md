## 산출물과 범위

- 원본 PNG 5장: 14,871,992바이트.
- 480px WebP 5장: 311,868바이트, 960px WebP 5장: 1,026,046바이트.
- WebP 15개 전체: 2,967,346바이트. 공유 JPG: 155,952바이트.
- 브라우저는 화면 폭과 픽셀 밀도에 맞는 사본을 선택한다. 위 합계는 실제 첫 화면 전송량이나 성능 측정 결과가 아니다.
- 공개 빌드: `dist/` 22개 파일. `scripts/public-assets.mjs`가 공개 파일 목록의 기준이다.
- 운영 시안·문서·백업·원본 PNG는 공개 빌드에서 제외한다.
- JS 문법 확인 및 공개 빌드 생성, 로컬 화면 미리보기 진행. 기존 자동 회귀 검사 묶음은 이번 구현 작업에서 재실행하지 않았다.
- 실제 저장·발송·인증·결제·서버 연동, GitHub 업로드·배포는 하지 않았다. 기존 PM 보류 결정 유지.
- OG 이미지는 로컬 산출물에 포함되지만 외부 공유에 적용하려면 추후 승인된 배포가 필요하다. 카카오 공유 결과는 확인하지 않았다.

## 되돌리기

백업: `backups/before-all-improvements-20260929/`.

1. 백업의 최상위 HTML/CSS/JS/MJS 파일을 프로젝트 루트의 같은 이름에 덮어쓴다.
2. 백업의 `scripts/build.mjs`와 `docs/`를 같은 위치에 복원한다.
3. `npm run build`로 공개 산출물을 다시 생성하고, 이 프로젝트의 로컬 서버를 종료한 뒤 `npm start`로 실행한다.
4. 이번에 추가된 WebP·공유 카드·공개 목록·추가 CSS는 복원된 소스에서 참조하지 않는다. 원본 사진은 바뀌지 않았다.

새 기능을 추가한 뒤에는 이 백업으로 덮어쓰기 전에 그 작업을 별도로 보관해야 한다.
