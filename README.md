# MyLodge_Business
MyLodge_Business 플랫폼 (홍보페이지, 주요 플랫폼 구현 - 담당자 : 연서흠)

## 현재 버전 — 사이트 틀 v0.1

2026-09-24 작업 범위는 홍보 사이트의 화면 틀과 GitHub 등록입니다.
전달받은 Figma Make 화면과 마이롯지 플랫폼 기획서를 기준으로 작성했습니다.
한즈시티의 디자인·인터페이스 공유 요구는 적용하지 않았습니다.

### 실행 방법

Node.js 20 이상에서 이 폴더를 열고 실행합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다.
별도 패키지 설치는 필요하지 않습니다.
원본 이미지(Unsplash)와 글꼴(Google Fonts) 표시에는 인터넷 연결이 필요합니다.
같은 포트를 사용하는 기존 미리보기가 있으면 먼저 종료합니다.

### 포함된 화면

소개, 이용 장면, 공동소유 구조, 프로젝트, 금액 안내, 참여 과정,
회원 서비스 소개, 확인 사항, FAQ, 상담 양식 등 10개 섹션입니다.
메뉴 이동, 서비스 탭, FAQ 펼치기, 관심 지역 선택, 입력 검사 동작을 포함합니다.

### 현재 제한

- 상담 양식은 체험용입니다. 입력 정보는 서버로 전송하거나 저장하지 않습니다.
- 직원 로그인·상담 관리, 실제 계약·결제·예약 기능은 아직 없습니다.
- 금액과 서비스 설명은 사전 안내 상태이며 공개 전에 승인된 정보로 확인해야 합니다.
- 원본과의 정밀 화면 대조 및 모바일 전체 검증은 다음 작업입니다.
- GitHub 업로드는 실제 서비스 배포와 별개입니다.

### 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 기본 문서·상단 메뉴·하단 안내 |
| styles.css | 색상·배치·모바일 스타일 |
| app.js | 10개 섹션과 화면 내 동작 |
| server.mjs | 로컬 미리보기 서버 |
| docs/DEVELOPMENT.md | 단계별 개발 범위와 현재 상태 |

문법 확인: `npm run check`
