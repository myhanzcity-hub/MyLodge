## ✦ A city is more than an address.

### 사는 곳을 넘어, 살아가는 방식을 연결합니다.

어느 동네에서 살지, 이주는 무엇부터 준비할지, 아이의 학교와 나의 일은 어떻게 찾을지.
새로운 도시에서의 생활에는 서로 이어지는 질문이 있습니다.

**한즈시티는 흩어진 생활의 선택지를 한곳에서 살펴보고, 필요한 상담과 서비스 연결을 요청할 수 있도록 돕습니다.**
